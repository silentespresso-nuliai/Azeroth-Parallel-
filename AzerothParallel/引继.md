# AzerothParallel 交接（引继）

> 最后更新：2026-11-25
> 本文重点：**每个 Lua 文件负责什么**。新 session 先看第 2 节，按任务只读相关文件，不要全目录扫描。

## 1. 项目一句话

魔兽世界 RP 插件：把官方职业 / 技能称呼，按“职业流派”的文化背景做本地化显示；并提供聊天弹幕、称谓覆盖、核心奥义、表情动作卡片、技能熟练度等 RP 辅助功能。

- 只改本地 UI，不替换全局 API，不改客户端资源，不碰服务器数据。
- 单 HTML 的网页规则不适用本目录；本目录按 WoW 插件规范执行。
- 用户全程简体中文交流；代码注释沿用“小白友好型”详细中文说明。

## 2. 每个 Lua 文件的职责（核心）

### `AzerothParallel.toc`
- 声明 `## SavedVariables: AP_DB`。
- 加载顺序：
  `Core → Danmaku → CombatEntry → Emotes → Terms → Data → Flavor → Overrides → CastBar → Network → Peers → Nameplate → Spotlight`。
- `Interface: 16001` 是用户写的，未必等于实际客户端，待 `/dump select(4, GetBuildInfo())` 确认。

### `Core.lua` — 主框架（书籍界面）
- 创建 `AP_MainFrame`（900×650，可拖动，默认隐藏，ESC 可关）。
- 底图使用 `Media/Book.tga`，整体是一本翻开的冒险日记；左右页容器透明，不再各画深色底框。
- 定义公共配色表 `AP_Theme`（`ink / inkSoft / accent / cream / line`）和 `AP_Theme.Paint()`。
- 4 个页签是从书底垂下的彩色书签丝带（`Media/Ribbon.tga`）：`设定 / 职业流派 / 奇遇社交 / 高光特写`。
- 页签花纹 `Media/Deco_1..4.tga` 叠加在整本书上，跟随当前页签切换（`decoArt`，BORDER 层）。
- 创建 `AP_Tabs`、`AP_Panels`；每个 Panel 带 `LeftPage` / `RightPage`（各 400×540）。
- 本地函数 `SelectTab(index)`；加载时默认 `SelectTab(2)`（职业流派），并把页签存进 `AP_DB.ui.lastTab`，`PLAYER_LOGIN` 恢复上次停留页。
- 设定页左页（`AP_Panels[1].LeftPage`）是插件介绍：标题、简介、版本、作者、原创声明、NGA/AFD/XHS 可复制链接。
  - 链接点击打开自建 `AP_CopyPopup`（可选中网址，Ctrl+C 复制）；不使用 StaticPopup 的 EditBox。
  - 作者/联系方式区块有软防伪签名：`BRAND` / `BRAND_SIGNATURE`；被改动时左页红字 + 聊天警告，不影响功能。
- `/AP` 命令：
  - 无参数：开关主面板；
  - `/AP addrep N`：调试加流派声望；
  - `/AP net [on|off]`：插件间互通开关；
  - `/AP spotlog`：高光调试日志开关；
  - `/AP castbar`：施法条识别诊断（查看是否找到 PlayerCastingBarFrame / 第三方 castbar 框架）；
  - `/AP brand`：打印作者区块当前签名与期望签名（改作者/链接后更新 `BRAND_SIGNATURE`）。
- `PLAYER_LOGIN` 打印欢迎横幅。

### `Danmaku.lua` — 聊天弹幕 + 设定页右页分页器
- 弹幕引擎：监听 `CHAT_MSG_SAY/YELL/PARTY/RAID/CHANNEL/WHISPER/GUILD`，过滤频道、创建飘屏 FontString、动画、字号/飞行时间。
- 对 `issecretvalue` 聊天内容做静默跳过。
- 设定页左页已改为插件介绍；原四个入口按钮（聊天弹幕 / 表情动作 / 正面形象 / 奇遇社交）统一隐藏，右页顶部分页器是唯一导航。
- 「聊天弹幕」分页内容：频道复选框、速度/字号滑条。
- **右页分页器**（设定页右页顶部）：
  - 四个分页按钮：`聊天弹幕 / 表情动作 / 正面形象 / 奇遇社交`；
  - `AP_SelectSettingsTab(key)`：key 为 `"danmaku"` / `"emote"` / `"model"` / `"peers"`；
  - 暴露 `AP_EmoteSettingsPage`、`AP_ModelSettingsPage`、`AP_PeersSettingsPage`；
  - 所有入口按钮都只切换右页，左侧设定页保持不变。
- 入口按钮登记：
  - `AP_SettingsEntryFrames` + `AP_RegisterSettingsEntry(frame)` 保留兼容；现在直接把传入按钮隐藏。
  - `AP_CloseDanmakuSettings()` 保留为空实现，兼容其他模块调用。
- 默认停在「表情动作」分页。

### `Emotes.lua` — 表情动作卡片 / 3D 正面形象
这是目前最大的 UI 模块，分几块：

**卡片容器**
- `AP_EmoteCard`：外层卡片，负责整体位置存档 `AP_DB.emote.pos`、拖动、统一显隐。
- 卡片 / 表情面板 / 3D 模型 / 话术列表统一使用 `MEDIUM` 层级；其中模型 `FrameLevel=5000`、话术列表 `FrameLevel=6000`，保证不被聊天框/动作条遮挡，同时暴雪自带窗口（任务、地图、人物属性、专业等通常在 `HIGH` / `DIALOG`）仍会盖在卡片之上。
- `AP_EmoteFrame`：真正的表情图标面板，右上角 × 只隐藏它，不隐藏上方的名牌/属性条。
- `/ape` = 开关整张卡片；`AP_EmoteUI.Show/Hide/Toggle` 供外部调用。
- 按住 Shift 拖动卡片；位置在 `PLAYER_LOGIN` 恢复。

**10 个表情按钮**
- 基础 8 个：讲笑话 / 要说的话 / 大笑 / 跳舞 / 欢呼 / 秀肌肉 / 火车 / 咆哮。
- 末尾 2 个自定义槽：名称 + 内容；内容以 `/` 开头按表情执行（`DoEmote`），否则说话。
- 所有“说出来”的话自动加 `【RP】` 前缀。
- 「要说的话」：24 条预设话术，滚动列表，点选后发送；`AP_EmotePickerScroll`。

**名牌 / 属性条 / 小图标**
- 名牌：`AP_DB.flavor.customName` + 当前职业/流派名（`AP_FlavorData` + `AP_DB.flavor.currentClass/currentFaction`），流派色；浅色主题自动压暗。
- 属性条：力量/敏捷/智力/精神/回蓝/护甲/耐久；处理 secret 值、缓存兜底；每秒刷新。
- 小图标 5 个：核心奥义（图标跟随当前流派，点击只打开核心页、不播放高光）/ 属性显隐 / 表情面板显隐 / 技能熟练度 / 主界面（固定打开设定页）。
- `AP_EmoteUI.Notify(text,r,g,b)`：声望/熟练度提示，固定显示在名牌上方；卡片隐藏时回退 `UIErrorsFrame`。

**3D 正面形象**
- 透明 `PlayerModel` 窗口（无背景/无边框），尺寸 720×660，默认锚定屏幕左下角（底边贴屏、左侧向右约 3cm），可 Shift 拖动；旧版位置会一次性作废（`modelPosVersion`）。
- 只有「战斗中第一次施法」触发；起手技能（如月火术）在施法事件时可能还没进战斗，会延迟 0.2 秒补检查。
- **只在人形态显示**：德鲁伊变形、萨满幽魂之狼等非人形态一律不显示；变形瞬间会通过 `UPDATE_SHAPESHIFT_FORM` 立即收起，避免猫/熊/狼的大模型留在屏幕上。非人形态施法不消耗本次战斗的展示机会。
- 被动进战（`AP_CombatEntry` 判定为 passive）**必定显示立绘**；有哭泣/受击动画时播放，没有时用甩头 + 「？！」错愕表演保持动态。
- **核心技能与正面形象解耦**：核心技能施放时正面形象不出现，只由 Spotlight 走高光；非核心技能正常显示正面形象。
- 模型 `FrameLevel=5000`（MEDIUM 层内），高于姓名牌、属性条、聊天框和动作条，不会被它们挡住；暴雪 `HIGH` / `DIALOG` 窗口仍在模型之上。
- 展示施法动作，`OnAnimFinished` 自动重播，避免僵住；约 2.5 秒 / 1.5 秒后收起。
- 顶部只有一条拖动条（文字「Shift + 拖动这里」），窗口主体点击穿透，避免战斗中挡住动作条。
- 位置存档 `AP_DB.emote.modelPos`；`showModel` 开关、`cardEnabled` 卡片显示状态也存档。
- 起手高光抑制：开启模型且卡片显示时，Emotes 会写全局 `AP_SuppressSpotlightSpell/At`，让 Spotlight 跳过同一次施法的起手高光。

**设定页**
- 表情动作页：显示卡片 checkbox、卡片风格 6 套（经典/烈焰/月光/森林/幽暗/任务）、两个自定义编辑器。
- 正面形象页：显示模型 checkbox + 说明；`AP_EmoteUI.OpenModelSettings()` 直接打开这一页。
- 主题由 `THEMES` + `ApplyTheme` 统一控制；quest 是亮羊皮纸风格。
- 左页「表情动作」「正面形象」按钮只切换右页分页，不直接开关功能。

**关键存档（`AP_DB.emote`）**
- `theme`、`custom[1/2] = {name,text}`、`showModel`、`cardEnabled`、`pos`、`modelPos`。

### `Terms.lua` — 称谓词条库（纯数据）
- 表名 `AP_Terms[职业Token]`：
  - `._common`：该职业所有技能/天赋的默认称呼；
  - `[流派id]`：只覆盖该流派叫法不同的词条。
- 词条格式：`{ category, official, alias, note }`。
- 分类：技能、天赋、变形、图腾、陷阱、钉刺、追踪、毒药、光环、守护、祝福、怒吼、姿态。
- 同名技能按 `official` 合并，流派覆盖 alias/note/category。

### `Data.lua` — 职业流派数据（纯数据）
- 表名 `AP_FlavorData[职业Token]`：
  - `className`、`classColor`；
  - `factions[] = { id, name, themeColor, reqFaction, races, icon, description, tiers }`。
  - `races` 可选；目前只作为德鲁伊的种族归属说明，不再限制可选性。
- `MakeTiers(base, top)`：生成 1~10 级头衔与经验阈值。
- 9 职业；德鲁伊已按种族拆成 4 个流派（暗夜精灵/牛头人/巨魔/天裔），其他职业仍是初稿。
- 被 Flavor / Emotes / Network / Spotlight 共同读取。

### `Flavor.lua` — 职业流派页 + 称谓典籍 + 技能熟练度
- Tab 2 全部 UI：职业书签、流派 Tab、声望条、头衔、履历、图标、描述、名字编辑、tooltip 开关。
- 声望：任务 +100；转投流派清零；`AP_DB.flavor.rep`。
- 流派不再受阵营/种族限制，全部可选。跨阵营转投弹 `AP_FLAVOR_HERETIC_CONFIRM`（标题「异类！」），确认后该流派的声望与熟练度成长减半（核心等级随熟练度同步变慢）。
- `BuildTermList(classToken, factionID)`：合并通用词条 + 流派覆盖；导出 `AP_FlavorManager.GetTermList`。
- 称谓典籍：右页切换模式，显示 `alias（官方：official）` + 备注。
- 技能熟练度：
  - 数据：`AP_DB.flavor.skillProf[official] = points`；
  - 只统计非「天赋」词条；
  - 成功施法有概率 +1：<100 30%，<200 20%，≥200 10%；
  - 上限 = 角色等级 × 5（60 级 300）；
  - 在称谓典籍每条下面显示 `熟练度 X/上限` + 文字条；
  - 提升提示为蓝色，和流派声望同色；只预览自己职业时显示。
- `AP_FlavorUI.OpenSkillBook()`：打开主面板 → 职业流派 → 称谓典籍（供 Emotes 小图标调用）。
- 事件：任务完成/区域变化写履历；`UNIT_SPELLCAST_SUCCEEDED` 练熟练度；登录/升级刷新等级缓存。

### `Overrides.lua` — 鼠标提示称谓覆盖
- 只在开关打开时包装 `GameTooltip` 的显示方法，在原函数后改第一行。
- 不改全局 `GetSpellInfo` 等 API，只影响自己看到的 tooltip。
- 优先走 spellID → 官方名查表；文本路径全部 `pcall`；secret 文本安静跳过。
- 导出 `AP_TooltipAlias.SetEnabled / IsEnabled`。

### `CastBar.lua` — 施法条称谓
- 与 tooltip 共用「应用到游戏内提示/施法条」开关。
- 只处理玩家自己的施法条（`PlayerCastingBarFrame` / `CastingBarFrame`），不碰目标条/姓名版。
- 用事件里的 spellID 或当前施法名称查别名；拿不到就跳过。
- 核心技能 15 级改名后，施法条会强制显示新名字，不再依赖 tooltip 开关。
- `/AP castbar` 诊断已识别到的施法条框架；第三方 UI 需要知道框架名才能支持。

### `Network.lua` — 插件间 RP 名互通
- 前缀 `AzerothPar`，协议 `1|流派简称|RP名字`。
- 只走小队/团队/公会 `SendAddonMessage`，带节流；不可用时安静降级。
- 收到后写 `AP_DB.peers[角色名] = { name, faction, updated }`。
- 导出 `AP_Network.Broadcast / SetEnabled / GetShortName`；`/AP net` 控制。
- 全程 secret 安全处理。

### `Peers.lua` — 奇遇社交（设定页 →「奇遇社交」分页）
- 入口在设定页左页「奇遇社交」；内容挂在 `AP_PeersSettingsPage`（Danmaku.lua 的右页分页）。
- 只读 `AP_DB.peers`，显示 RP 名 + 流派简称 + 更新时间。
- 全部自建控件，不碰暴雪单位框架；导出 `AP_PeersUI.Refresh`。
- 原 Tab 3 页面保留为空书签，不再挂内容。

### `Nameplate.lua` — 姓名版 RP 名（新客户端停用）
- 原理：只替换姓名版名字 FontString 的 `SetText` 输入。
- 有 `issecretvalue` 的客户端直接停用，避免污染姓名版导致暴雪代码报 secret number 错误。
- `AP_Nameplate.supported`、`RefreshAll()` 保留给老客户端。

### `Spotlight.lua` — 核心技能培养 + 核心奥义
- Tab 4「核心奥义」UI：左页展示核心技能卡片（图标/名字/Lv/熟练度）、核心介绍、等级解锁；右页放触发范围、高光开关、喊话/改名/音效等操作。
- 核心技能：从本职业「技能」词条选择，过滤 1 级初始技能、buff/非伤害、种族技能；存档 `coreSpell` / `coreAlias` / `coreDesc`。
- 等级 = `floor(AP_DB.flavor.skillProf[official] / 10) + 1`，最高 30；5 级喊话、15 级改名、20 级高光、30 级音效。
- 试放：所有窗口统一 440×150；第一次自己按按钮位置（左上/右上），第二次自动相反方向，第三右中、第四左中，第五在中央顶部触发阿尔萨斯彩蛋；音效按 0.18 秒错开，上限 5 次不循环。
- 高光覆盖层：职业色速度线、头像、大字、音效、远程队友 5 槽位广播（`H1|...`）。
- 施法判断：只认核心技能；核心技能只走高光，不触发 3D 正面形象；非核心技能走 Emotes 正面形象。
- 释放间距：右页可调 1~10 分钟（`AP_DB.spotlight.cooldownMinutes`），默认 1 分钟；未选核心技能时左页隐藏试放/位置按钮。
- 改名同步：称谓典籍（Flavor）、鼠标提示（Overrides）、施法条（CastBar）。
- 调试：`/AP spotlog`、`/AP spotprof N`。
- 导出：`AP_Spotlight.Show / ShowRemote / RefreshList / RefreshCoreUI / GetCoreLevel / IsCoreSpell / AddCoreProf / ToggleDebug`。

### `Media/`
- `Media/sounds/`：Spotlight 自定义音效。
- `Media/Book.tga`：主面板书籍底图（左上角 900×650 区域）；`Media/Ribbon.tga`：顶部页签与职业书签共用的丝带贴图。

## 4. 存档结构（`AP_DB`）

- `AP_DB.flavor`：`currentClass`、`previewClass`、`currentFaction`、`previewFaction`、`customName`、`tooltipAlias`、`rep[流派id]`、`history`、`skillProf[官方技能名]`。
- `AP_DB.danmaku`：`channels`、`time`、`fontSize`。
- `AP_DB.network.enabled`、`AP_DB.peers`。
- `AP_DB.spotlight`：`enabled`、`sound`、`coreSpell`、`coreAlias`、`coreDesc`、`coreChatEnabled`、`chatText`、`cooldownMinutes`、`soundIndex`、`groupOnly`、`broadcast` 等。
- `AP_DB.emote`：`theme`、`custom[1/2]`、`showModel`、`cardEnabled`、`pos`、`modelPos`、`modelPosVersion`。
- **最大坑**：SavedVariables 可能在 Lua 文件执行完之后才注入，文件顶部初始化会被覆盖。
  - 运行时读写前必须 `Ensure` 当前表；不要捕获加载时的旧表引用。
  - 典型修复：自定义表情保存时重新取 `AP_DB`；登录 / `ADDON_LOADED` 后刷新 UI。

## 5. UI 结构速查

- 主面板是浅色羊皮纸书页，所有页面文字统一用 `AP_Theme` 的深色墨水；改配色优先改 `Core.lua` 的 `AP_Theme`。

## 6. 红线与已知坑

1. **secret 值**：不要直接比较/拼接/运算 `issecretvalue` 为 true 的值；读取前 `pcall` + `IsSecret`，读不到就跳过。
2. **不要改写暴雪姓名版 / 单位框架**：会污染整个姓名版，触发 secret number 报错；`Nameplate.lua` 在新客户端已停用。
3. **不要替换全局 API**：`GetSpellInfo`、`GetSpellBookItemName`、`GetSpellLink` 等一律不碰；`Overrides.lua` 只包 `GameTooltip` 实例方法。
4. **不要改 3D 法术特效颜色**：客户端资源，无接口。
5. **插件通信只用 `SendAddonMessage`**，仅小队/团队/公会，带节流。
6. **不要改暴雪受保护控件**；优先自建 Frame / FontString / Texture / Animation。
7. **PlayerModel 坑**：
   - 窗口高度变高会连同镜头一起放大，不一定“露出更多身体”；
   - `SetPosition` 在部分客户端会把人推出画面，不要依赖它做微调；
   - 模型窗口大面积 `EnableMouse` 会挡住动作条，导致“插件行为导致错误”；只留顶部拖动条响应鼠标。
8. **加载顺序依赖**：Emotes 比 Data/Flavor/Spotlight 先加载；运行时再访问 `AP_FlavorData`/`AP_Terms`，不要文件加载时读。
9. **本机没有 Lua 解释器**；最终以游戏内 `/reload` 为准。
