# 艾泽拉斯平行宇宙 (Azeroth Parallel)

> 给 RP 角色的一本冒险日记。
> 版本 1.0.0-beta.9 · 作者：怒里哀

---

## 这是什么

**Azeroth Parallel** 是一个面向角色扮演（RP）玩家的界面增强插件。

它不会改变游戏平衡，也不会修改任何官方数据。它做的事情是：把职业、技能、称谓、履历和社交名片，整理成一本能跟着你角色一起成长的“书”。

打开 `/AP`，你会看到一本翻开的冒险日记：

- 左边是**你的身份**：职业流派、称号、声望、最近履历。
- 右边是**你的故事**：流派介绍、称谓典籍、技能熟练度。
- 书页下方挂着四枚彩色书签：设定、职业流派、奇遇社交、高光特写。

所有内容都只保存在你自己的电脑上。

## 最近更新（1.0.0-beta.9）

- **50 级专精头顶特效**：满级后按专精显示光环、上升、坠落、脉冲、光柱等不同特效，德鲁伊四专精各自独立（平衡德为月光柱）；触发间隔可调。
- **40 级流派施放特效**：核心技能起手时按职业与流派显示不同颜色和粒子，职业流派页可以逐个预览。
- **表情动作卡片升级**：10 个快捷键、24 条预设话术、最近常用 10 条、6 套主题；卡片首个图标改为流派图标，点击可直接打开核心页。
- **称谓典籍新版排版**：技能熟练度逐条展示，提升时显示蓝色提示。
- **核心页按等级显示**：描述与试放内容随等级逐步解锁，页签改名并重新排序。
- **存档保护**：插件更新时不再覆盖你的玩家存档。

## 安装

1. 关闭游戏。
2. 解压插件，得到 `AzerothParallel` 文件夹。
3. 把这个文件夹放进：

   ```
   World of Warcraft\_retail_\Interface\AddOns\AzerothParallel
   ```

   无限服则放进对应的 `_forever_` 目录。

4. 确认路径是：

   ```
   ...\Interface\AddOns\AzerothParallel\AzerothParallel.toc
   ```

   也就是**不要**出现 `AzerothParallel\AzerothParallel` 这种多套一层的情况。

5. 启动游戏，在角色选择界面确认插件已启用；进入游戏后输入 `/AP`。

如果插件列表显示“过期”，勾选“加载过期插件”即可。插件本身使用了较新的客户端接口，建议在较新的客户端版本上使用。

3. 在“聊天弹幕”里选择想变成弹幕的频道。

## 功能详解

### 一、职业流派

主面板的第二枚书签。

- **9 个职业、34 个流派**：每个流派都有自己的名称、图标、介绍和十级头衔。
- **德鲁伊按种族区分**：
  - 暗夜精灵：塞纳里奥（联盟）——月光与翡翠梦境中的自然守护者。
  - 牛头人：符文图腾（部落）——与大地母亲和先祖同行的草原德鲁伊。
  - 巨魔：洛阿德鲁伊（部落）——借洛阿与野兽之形作战的丛林祭司。
  - 天裔：夜爪德鲁伊（中立）——隐入阴影、倾听草木低语的隐秘一脉。
- **所有流派都可转投**：不再受阵营/种族限制。跨阵营转投会弹出「异类！」确认；确认后，该流派的声望与熟练度成长减半，核心等级也会随熟练度同步变慢。
- **职业书签**：左页边缘的彩色丝带代表不同职业，点一下就能预览那个职业的流派图鉴。自己的职业会排在第一枚。
- **流派声望**：完成任务会增加当前流派声望（每次 +100）。声望推进阶级时，会在聊天框和卡片上方提示。
- **头衔**：每个流派有 10 级头衔，从“见习”一路到专属称号。
- **履历**：完成任务、抵达新区域时自动记录，左页随时回看。
- **称谓典籍**：右页可以切换到技能 / 天赋的 RP 称谓对照表，查看“本流派叫法（官方原名）”，并附备注。
- **技能熟练度**：使用技能会按概率提升熟练度。上限为角色等级 × 5。熟练度只统计称谓典籍里的非天赋条目，逐条显示文字进度条。
- **RP 名字**：点击左页名字或羽毛笔即可修改，名字会保存，并同步广播给装了插件且在同一小队 / 团队 / 公会里的玩家。
- **称谓提示开关**：在称谓典籍页勾选“应用到游戏内提示/施法条”，鼠标悬停技能时第一行、以及你自己的施法条会显示当前流派的叫法。默认开启，关闭后会记住；只影响你自己的界面，别人看不到。

### 二、设定

- 左页是插件介绍：简介、版本、作者、原创声明，以及 NGA / AFD / XHS 链接（点击可复制）。
- 聊天弹幕 / 表情动作 / 正面形象 / 奇遇社交 统一从右页顶部的分页按钮进入。
- **聊天弹幕**：把说、喊、小队、团队、频道、密语、公会消息变成从屏幕边缘飘过的弹幕。可以单独勾选频道，调整飞行时间（5–30 秒）和字号（10–40）。
- **表情动作卡片**：一个可以常驻屏幕的 RP 快捷卡片。
  - 8 个基础动作：讲笑话、要说的话、大笑、跳舞、欢呼、秀肌肉、火车、咆哮。
  - 2 个自定义按钮：名称和内容都能自己填。内容以 `/` 开头时当作表情 / 命令执行，否则当作说话。
  - 24 条预设话术，点“要说的话”可以滚动挑选。
  - 所有说出口的内容会自动带上 `【RP】` 前缀，方便和普通聊天区分。
  - 6 套卡片配色：经典、烈焰、月光、森林、幽暗、任务。
- **正面形象**：开启后，战斗中第一次施法时，会在姓名卡片上方显示一个透明背景的 3D 角色正面模型，并播放施法动作。顶部有一条拖动条，窗口主体不挡鼠标。

### 三、奇遇社交（设定页）

- 打开 `/AP` →「设定」→ 右页顶部「奇遇社交」。
- **同好名录**：记录装了本插件、并且和你出现在同一小队 / 团队 / 公会里的玩家。
- 显示对方的 RP 名、流派简称和最近一次更新时间。
- 只保存在本地，不会上传到任何服务器。

### 四、核心奥义

- 在「核心」页左页选择一个核心技能，长期培养。
- 熟练度与「称谓典籍」共用同一份数据；每 6 点熟练度升 1 级，最高 50 级。
- 等级解锁：
  - **15 级**：修改核心技能名字，并同步到称谓典籍、鼠标提示和施法条。
  - **20 级**：解锁高光特写。
  - **30 级**：解锁本地音效选择。
  - **40 级**：解锁本流派的施放特效；释放核心技能后出现，持续到脱战。
  - **50 级**：解锁专精头顶特效，与 40 级特效同时存在；德鲁伊按四个专精区分，平衡德为银白月光。
- 核心技能施放时只显示高光；非核心技能仍显示 3D 正面形象，两边互不抢镜。
- 右上角「×」重练，会清空该技能的熟练度并解除选择。
- 释放间隔可在右页调整（1~10 分钟或无限制，默认 1 分钟）；特效和高光共用同一触发与间隔。
- 可切换触发范围（所有人 / 仅组队·团队）和高光总开关。
- 「试放我的高光」会先收起书本，依次演示五人高光和当前流派特效（50 级会叠加头顶特效），结束后自动恢复界面。
- 职业流派页左页「称谓典籍」下方有「特效预览」按钮：收起书本预览当前预览流派的特效 1.5 秒。
- **位置**：高光在右上或左上。
- **音效**：随机、固定播放 `Media/sounds` 里的本地音效，或选择「已关闭」。

## 存档与隐私

- 存档变量：`AP_DB`
- 位置：

  ```
  World of Warcraft\_retail_\WTF\Account\<账号>\SavedVariables\AzerothParallel.lua
  ```

- 想重置全部数据，退出游戏后删除上面这个文件即可。
- 插件之间只通过官方 `SendAddonMessage` 交换 RP 名字和流派简称，范围仅限小队、团队和公会。
- 不会读取、修改或上传任何账号数据。

## 兼容性与已知限制

- 插件使用了现代客户端接口（`BackdropTemplate`、`C_Spell`、`issecretvalue` 等），建议在较新的客户端版本上使用。
- 部分客户端会用 `secret value` 机制屏蔽聊天内容；遇到这类消息时，弹幕会安静跳过，不会报错。
- 姓名版 RP 名改写在新客户端已被系统限制，插件会自动停用这一功能，改用“同好名录”展示。
- 插件目录中的自定义音频在部分客户端可能被限制播放；没有声音时不影响其他功能。
- 主面板文字使用深色墨水配浅色羊皮纸。如果你使用了改变 UI 缩放的插件，字体观感可能略有差异。
- 本插件不替换任何暴雪全局 API，只包装 `GameTooltip` 的显示方法，正常情况下不会与其他插件冲突。

## 常见问题

**Q：输入 `/AP` 没反应？**
A：确认插件目录名是 `AzerothParallel`，并且 `AzerothParallel.toc` 直接位于这个目录下。然后在插件列表中确认已启用。

**Q：插件列表显示“过期”？**
A：勾选“加载过期插件”。或把 `AzerothParallel.toc` 第一行的 `## Interface:` 改成你客户端的实际版本号（进游戏输入 `/dump select(4, GetBuildInfo())` 查看）。

**Q：弹幕没有内容？**
A：先确认对应频道已经勾选；部分客户端会过滤聊天内容，这类消息不会生成弹幕。

**Q：高光没有声音？**
A：确认 `Media\sounds` 里的 `.ogg` 文件存在。部分客户端不允许插件播放自定义音频。

**Q：名字版上看不到 RP 名？**
A：新客户端已禁止插件改写姓名版。请用「设定 → 奇遇社交」查看。

**Q：字体看起来模糊？**
A：这与客户端字体和 UI 缩放有关。可以在游戏设置里调整 UI 缩放，或换用更清晰的客户端字体。
